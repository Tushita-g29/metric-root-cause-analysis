# Automated Root-Cause Analysis Tool for Business Metrics

This project will help identify why a business metric suddenly changed, especially when revenue drops or spikes unexpectedly. It is designed for beginners and will combine data analysis, statistical testing, and simple AI-generated explanations to help explain what is most likely driving the change.

The tool will detect a revenue anomaly, test fixed hypotheses for region, device, product category, and traffic source, and only report evidence backed by statistical tests. It will avoid guessing by checking whether the observed change is statistically meaningful before presenting a possible cause.
